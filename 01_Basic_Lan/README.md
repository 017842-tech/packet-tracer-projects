# Basic LAN Network

##  Overview

This project demonstrates a simple LAN setup using a switch and two PCs.

##  Concepts

* IP Addressing
* LAN communication
* Switch-based connectivity

##  Topology

Two PCs connected via a switch.

##  Configuration

PC0: 192.168.1.10
PC1: 192.168.1.11

##  Test

Ping between devices successful.
