##  Project Notes — Basic LAN

### Commands Used
- ping → Verified connectivity between PCs
- ipconfig → Checked IP configuration on each device

---

### Issues Encountered
- Incorrect IP addressing prevented communication
- Devices not in same subnet caused ping failure

---

### Troubleshooting Steps
1. Verified IP addresses on each PC
2. Ensured all devices were in the same subnet (192.168.1.x)
3. Tested connectivity using ping

---

### Key Learning
- Devices in the same subnet communicate without a router
- Switch forwards traffic using MAC addresses (Layer 2)
- IP addressing must match subnet for communication

---

### Takeaway
This project established the foundation of networking:
IP addressing + switch connectivity = basic communication
